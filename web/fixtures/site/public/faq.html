Frequently asked questions

Is this fixture a real product?

No. It is a control group for the test suite.

What is intentionally missing?

Forms, an app, and a database. Those are covered by the distributed kit.

Why does consent live in the footer?

It does not; the banner is a fixed dialog. The footer links the policies.

Can I run this in CI?

Yes. Start the server, set SITE_URL, and run Playwright.

Does a green run mean the site is good?

No. It means the checks that exist did not find these specific problems.
